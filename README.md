# Devvrath Tewatia — Portfolio Website

A lightweight, responsive static portfolio for robotics, machine learning, and computer vision applications.

## Contents
- `index.html` — landing page and project summaries
- `styles.css` — responsive styling
- `assets/Devvrath_Tewatia_CV.pdf` — CV copy with phone number removed for applications that request no phone/address in the CV
- `assets/UAV_Railway_Inspection_Coursework_Review.pdf` — coursework report, labelled as a review rather than an implemented UAV system

## Publish free with GitHub Pages
1. Create a new public GitHub repository named `devvrathtewatia.github.io` (if that repository name is available and not already in use).
2. Upload the contents of this folder to the repository root: `index.html`, `styles.css`, and `assets/`.
3. In the repository, open **Settings → Pages** and select deployment from the `main` branch and `/ (root)`.
4. Wait for GitHub Pages to finish deploying, then open the published URL and test the CV and report links from a private/incognito browser.
5. For the OMRON form, use the public page URL with the CV prominently linked. If the form explicitly expects the PDF itself, use the direct hosted PDF URL ending in `/assets/Devvrath_Tewatia_CV.pdf`.

## Before submitting
- Make sure all project metrics are defensible from your logs/report.
- Keep the defect-classification repository link absent until the project code is ready to share.
- No phone number or physical address appears in the hosted CV.
- The CNC energy results are explicitly described as simulation-based.
- The UAV entry is labelled as a coursework literature review, not a completed robot implementation.
- Check sharing/access permissions and verify the public URL in a logged-out browser.

## Local preview
Open `index.html` in a browser. No build step or package installation is required.
